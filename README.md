# Grass Overhaul — Sculpt Smooth Hills and Natural Landscapes

Grass Overhaul 9minecraft Mod brings detailed turf shapes to help you craft smoother landscapes. The mod adds carpet-style sod layers, slabs, and stairs for every standard ground type in the game. You can stack thin sod sheets like snow layers to make gentle hills, garden beds, and smooth walkways. Every block keeps its proper biome tint and matches default terrain textures. It works on both singleplayer worlds and multiplayer servers.

## What this build is

An unofficial rebuild of **ElocinDev**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
